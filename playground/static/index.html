A few things to know.

What can I change in the playground?

You can choose a framework and call direction. Both the code and prompt are read-only. Download the example to edit and run your own version with your own credentials.

Do both examples use LiveKit Cloud?

Yes. LiveKit Cloud carries the phone audio for both. Pipecat runs an explicit speech pipeline; LiveKit Agents runs a native agent session. Both examples use Deepgram, OpenAI, and Cartesia.

Can the playground call my phone?

Yes. In “Call my phone”, verify your mobile by SMS, then press the call button. Your selected AI agent calls only that verified number using the fixed prompt. Calls last up to two minutes, with three calls per number per day.

What is included in a download?

Agent source, the fixed demo prompt, pinned direct dependencies, credential placeholders, inbound and outbound trunk templates, an outbound call script, a setup README, and the MIT license. Your demo number and real credentials are never included.
